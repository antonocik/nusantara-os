# Nusantara SDDM Theme

Tema login SDDM merah-putih ala Garuda dr460nized.

- Background gradient `#0b0e14` → `#1e0a12` + glow merah `#e11d48`
- Logo `/usr/share/pixmaps/nusantaraos.svg`
- Jam live kanan atas, footer `Nusantara OS • Merdeka • 2026`

Aktif via `/etc/sddm.conf.d/99-nusantara.conf` (`Current=nusantara`).

Ganti logo: timpa file SVG di atas, atau edit `source:` di `Main.qml`.
